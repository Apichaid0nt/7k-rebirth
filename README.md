7K Minigame Auto-Solver 🃏
บอทช่วยเล่นมินิเกมเปิดป้ายในเกม Seven Knights โดยใช้เทคนิค Image Recognition (OpenCV) ในการจดจำใบหน้าตัวละครและช่วยหาคู่ที่เหมือนกันให้อัตโนมัติ

✨ คุณสมบัติ (Features)
Auto Scanning: ตรวจจับหน้าต่างเกมและตำแหน่งของไพ่โดยอัตโนมัติ

Memory System: จดจำตำแหน่งของตัวละครที่เคยเปิดไปแล้ว

Smart Matching: เมื่อเจอคู่ที่ตรงกัน บอทจะทำการคลิกให้ทันที (โหมด Auto)

DPI Fix: รองรับการปรับสเกลหน้าจอของ Windows ไม่ทำให้ตำแหน่งเมาส์เพี้ยน

🚀 วิธีการใช้งาน (สำหรับผู้ใช้ทั่วไป)
เตรียมไฟล์: ดาวน์โหลดไฟล์ 7k[minigame].exe และโฟลเดอร์ image ไปไว้ในที่เดียวกัน

เปิดเกม: เปิดเกม Seven Knights และไปที่หน้ามินิเกมเปิดป้าย

รันบอท: เปิดไฟล์ 7k[minigame].exe (Run as Administrator หากบอทคลิกในเกมไม่ได้)

ควบคุม:

กดปุ่ม F เพื่อเปิด/ปิด ระบบ Auto Play (คลิกอัตโนมัติ)

กดปุ่ม R เพื่อ Reset ข้อมูลการจำไพ่ (ใช้เมื่อเริ่มเกมกระดานใหม่)

กดปุ่ม Q เพื่อปิดโปรแกรม

🛠 สำหรับ Developer (Python)
หากต้องการรันผ่าน Source Code หรือนำไปพัฒนาต่อ:

1. ติดตั้ง Library ที่จำเป็น:
Bash

pip install opencv-python numpy mss pygetwindow keyboard pydirectinput


2. โครงสร้างไฟล์:
Plaintext

├── mini[image].py      # ไฟล์หลักของโปรแกรม
├── image/              # โฟลเดอร์เก็บไฟล์ภาพอ้างอิง
│   ├── back.png        # ภาพหลังไพ่ (ใช้ตรวจจับตำแหน่ง Grid)
│   ├── btn_restart.png # ปุ่มเริ่มใหม่
│   └── ...             # ไฟล์ภาพตัวละครต่างๆ
└── 7k[minigame].exe    # ไฟล์ที่ Build สำเร็จแล้ว
3. การตั้งค่าที่สำคัญ (Config):
ในไฟล์ mini[image].py คุณสามารถปรับแต่งค่าเหล่านี้ได้:

TARGET_WINDOW_KEYWORD: ชื่อหน้าต่างเกม

GRID_ROWS / GRID_COLS: จำนวนแถวและคอลัมน์ของไพ่

MSE_MATCH_THRESHOLD: ค่าความแม่นยำในการเทียบภาพ (ถ้าน้อยจะยิ่งเป๊ะ)

⚠️ ข้อควรระวัง
ความละเอียดหน้าจอ: ควรเปิดเกมในโหมด Windowed และไม่ควรขยายหน้าต่างจนภาพแตก

โฟลเดอร์ Image: บอทจำเป็นต้องมีภาพในโฟลเดอร์ image เพื่อใช้ในการเปรียบเทียบ หากไม่มีภาพตัวละคร บอทจะทำได้เพียงจดจำตำแหน่งแต่จะไม่รู้ว่าเป็นตัวอะไร
